# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security issue in **whyTrace.ai**, please report it responsibly rather than opening a public GitHub issue.

Please email the maintainer directly at:
**tanishrajput673@gmail.com**

Please include:
- A description of the vulnerability and its potential impact.
- Steps or a minimal proof of concept to reproduce the issue.
- Any suggested remediations if available.

We acknowledge receipt of reports within 48 hours and work toward a fix promptly.
